# Structure du projet
## Les dossiers et fichiers
1.  En dehors de la page d'accueil, toutes les autres pages seront stockées dans **/src/pages/**
2. Les feuilles de styles CSS sont regroupées dans **/src/assets/css/**
    - le dossier **home** regroupera tous les styles de la page d'accueil
    - le dossier **about** regroupera tous les styles de la page à propos
    - le dossier **layouts** contiendra les styles pour le header, footer, et le container principale

## Aller sur GitHub
Chaque participant impliqué dans l'étape de développement (codage) doit :
1. Cloner le dépôt ***https://github.com/benoitmondjo/Portail_portfolio.git***
2. créer une branche dans laquelle il travaillera.
3. La branche sera nommée comme suit:
    - **feature/nom_de_la_tache** (exemple : **feature/header** si tu codes le **header**; **feature/home_hero** si tu codes le **hero** qui est contenu dans la page d'accueil; **feature/about_sponsor** si tu codes la partie **sponsor** de la page à propos.)
4. A chaque fois qu'un contributeur aura terminé sa tâche, il me contactera afin que je lui accorde les droits permettant d'effectuer un **push** de sa branche de travail.
5. Pensez à faire un **git pull orgin develop** pour recevoir d'eventuelles directives.

#### N.B: Les codeurs de la page about( à propos) n'ont pas la responsabilité de coder le **header** et le **footer.**
